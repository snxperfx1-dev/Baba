# F72 — Trader's Heuristics Ledger

A living record of the **fluid rules** — the compressed, intuitive relationships
that lived only in one trader's perception. The point of this file is durability:
intuition in a single head is fragile; written down, it survives. These are not
rigid `IF x THEN y` gates — they are *contextual relationships* the engine should
eventually weigh, the way the eye weighed them in real time.

Each entry: the observation, what it implies, and (where known) the underlying
*why* (participant behaviour / curve mechanics), so it can later be encoded.

---

## Session structure

### H-001 · Asian internal break → no deep Frankfurt test
- **Observation:** If price breaks its *own internal structure within the Asian
  session* (Asia "breaks on itself"), then the Frankfurt session will **not** give
  a deep test.
- **Implication:** Frankfurt continues **expanding off the Asian range** rather than
  retracing deeply back into it. Don't wait for a deep pullback that won't come.
- **Range-size tell:** The **size of the Asian range (in pips, per pair)** carries
  meaning about the character of the coming move — calibrate per instrument
  (each pair has its own "normal" Asian range).
- **Why (curve view):** an internal break inside Asia means a child curve has
  already transitioned *inside* the session — the energy has already shifted, so the
  parent doesn't need to return for a deep test; it just continues expanding.

## How to use this ledger
- Add a new entry every time a fluid rule surfaces (session behaviour, range sizes
  per pair, "no deep test" tells, compression→recursion feel, flip interactions,
  terminal-sequence reads).
- Keep them as relationships, not constants — note what they depend on.
- Over time these become the comparative/relational logic F72 reasons with, and a
  permanent record independent of any one person's memory.
